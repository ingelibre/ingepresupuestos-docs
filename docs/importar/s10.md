# Copias de seguridad .bak, .bkf y .S2K

Algunos programas de presupuestos guardan sus bases como **copias de seguridad de SQL Server** (`.bak`, `.bkf` o `.S2K`). IngePresupuestos las abre con ayuda de **IngeConverter**, una herramienta gratuita que se descarga junto al programa.

## Qué necesitas

- El archivo de copia de seguridad: **`.bak`**, **`.bkf`** o **`.S2K`**.
- **IngeConverter** (incluido gratis). Si no lo tienes, el programa te ofrece descargarlo cuando eliges importar una copia de seguridad.

## Pasos

1. En IngePresupuestos: **Importar** y elige el origen de las copias de seguridad.
2. Selecciona tu archivo `.bak` / `.bkf` / `.S2K`.
3. IngeConverter procesa la copia y la convierte a un proyecto de IngePresupuestos.
4. Confirma. El proyecto aparece en tu lista con sus partidas, ACU e insumos.

!!! info "Primera vez en Windows"
    IngeConverter usa una base de datos local (SQL Server LocalDB) para leer las copias de seguridad. La primera vez puede pedirte instalar un componente; sigue las indicaciones y, si te lo solicita, **reinicia** antes de volver a importar.

## Versiones soportadas

Se soportan las copias de seguridad de las versiones modernas. Las copias muy antiguas (del año 2000 y anteriores) **no** están soportadas por ahora.
